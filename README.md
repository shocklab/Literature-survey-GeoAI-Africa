# Literature-survey-GeoAI-Africa

Study records and figure code for the review "GeoAI for Africa: A Survey of Data Gaps, Methods, and the
Path Toward Inclusive Geospatial Intelligence" (Ocholla, Alaagib, Hacheme, Gbodjo, Tadesse and Shock).
Each release is archived on Zenodo: https://doi.org/10.5281/zenodo.22745736 resolves to the latest version.

## Contents

| Path | What it is |
|---|---|
| `figures/source/Reviewed_articles_only.xlsx` | The included studies and their coded attributes. `Studies` has one row per study, including `Imagery access` and six author-affiliation columns (`n_institutions`, `inst_countries`, `collab_breadth`, `has_african_inst`, `african_leadership`, `cross_sector`) that `fetch_affiliations.py` derives from `institutions_long`; `Selected_articles` holds the full extraction; the `*_long` sheets list methods, EO data, indices, countries, weather and DEM sources, tasks, platforms and journals one entry per row; `institutions_long` lists each study's author institutions with OpenAlex id, country, type, the university a sub-unit belongs to, and whether the row came from OpenAlex or was entered by hand; `PRISMA` holds the search and screening counts; `Abbreviations` expands the short forms. |
| `figures/source/lookups.json` | Mappings from the names used in the workbook to the categories in the figures (methods, sensors, platforms, weather products, repository types, spatio-temporal categories, ISO3 country codes). For the collaboration figure: OpenAlex institution types to partner categories, per-institution overrides, studies pinned to their hand-entered institutions, the African ISO2 codes and country display names. |
| `figures/source/Africa_Countries.geojson` | Country boundaries for the map. |
| `figures/build_figures.py` | Generates the figures, and the counts quoted in the text, from the three source files. |
| `figures/fetch_affiliations.py` | Looks up each study's author institutions in OpenAlex and writes the `institutions_long` sheet, then refreshes the affiliation columns of `Studies`. Needs network access; run it only when the studies change. |
| `figures/check_supp_refs.py` | Checks that each "Table S*n*" in the manuscript refers to a table the supplementary defines. |
| `figures/style.tex` | Colours and styles shared by the figures. |
| `figures/generated/numbers.tex` | The counts and percentages quoted in the text, one `
ewcommand` each, written by `build_figures.py`. `fig-prisma.tex` and the manuscript read their numbers from it. |
| `figures/generated/NUMBERS.md` | Every derived number with its definition and, where the paper states one, the value the paper gives. |
| `figures/fig-*.tex` | The figures, as TikZ and pgfplots. `fig-prisma.tex` is drawn by hand with its counts taken from `numbers.tex`; the rest are generated by `build_figures.py`. |
| `figures/GeoAI_overview_figure.png` | The conceptual overview figure (Earth observation, machine learning and cloud computing meeting in GeoAI, the application domains, and the key constraints). Drawn by hand, not generated. |

## Generating the figures and counts

```
pip install -r figures/requirements.txt
python3 figures/build_figures.py
```

The script finds its inputs relative to its own location, so it can be run from any directory. It writes
`fig-yearly.tex`, `fig-domain.tex`, `fig-methods.tex`, `fig-models-year.tex`, `fig-journals.tex`,
`fig-spatiotemporal.tex`, `fig-resolution.tex`, `fig-infrastructure.tex`, `fig-collaboration.tex` and `fig-choropleth.tex` to `figures/`, and two files to
`figures/generated/`:

- `numbers.tex`, the counts and percentages quoted in the text, one `\newcommand` each, for example
  `\nStudies` for the number of included studies;
- `NUMBERS.md`, every derived number with its definition.

Re-run it after any change to the workbook, then copy the figure files and `numbers.tex` into the
manuscript's `figures/` folder.

## Refreshing the author affiliations

The collaboration figure reads the `institutions_long` sheet, which is filled from OpenAlex rather than
coded by hand. When studies are added or removed:

```
python3 figures/fetch_affiliations.py
python3 figures/build_figures.py
```

The first script queries OpenAlex by DOI (by title for a study without one), writes one row per study and
institution, and recomputes the six affiliation columns of `Studies`. Rows whose `source` starts with
`manual` survive a re-run, so a study OpenAlex has no affiliations for can be entered by hand from the
article; a study listed in `pinned_studies` in `lookups.json` keeps its manual rows even when OpenAlex has
the paper, for the cases where OpenAlex attributes an author wrongly. A department or institute of a
university counts as academic whatever OpenAlex types it, and `institution_type_overrides` names the
institutions whose category is fixed by hand. `build_figures.py` stops if the `Studies` columns disagree
with `institutions_long`, or if an institution has no category.

## Using the output in LaTeX

The manuscript loads the styles and counts in its preamble, after `pgfplots` and the TikZ libraries
`arrows.meta`, `positioning`, `calc`, `fit` and `backgrounds`:

```latex
\input{figures/style.tex}
\input{figures/numbers.tex}
```

Each figure is then included with `\input{figures/fig-yearly.tex}` and so on, and counts are written as
macros: `\nStudies{} studies`, `\pctSentinelTwo\%`.

## Checking supplementary table references

From the folder that holds `manuscript_review.tex` and `supplementary_S1.tex`:

```
python3 figures/check_supp_refs.py
```

or give that folder as an argument from anywhere else. It lists each supplementary table with its number
and whether the main text cites it, and exits with status 1 if the main text cites a table number the
supplementary does not define or the supplementary has a table the script does not know.
